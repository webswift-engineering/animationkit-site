Min Stack

Design a stack that supports push, pop, top, and retrieving the minimum element, each in constant time. Implement the MinStack class: push adds an element onto the stack, pop removes the element on the top of the stack, top gets the top element of the stack, and getMin retrieves the minimum element in the stack. You must implement a solution with O(1) time complexity for each function.

input:ops =[push,push,push,getMin,pop,getMin]
output: [null,null,null,3,null,3]
· -2^31 <= val <= 2^31 - 1
· pop, top and getMin operations will always be called on non-empty stacks
· at most 3*10^4 calls will be made to push, pop, top, and getMin
